# AlarmX — Privacy Policy

The privacy policy for **AlarmX**, an Android alarm clock that cannot be
dismissed, only defeated.

Published at <https://arun150719.github.io/alarmx-privacy/> and linked from the
app's Google Play listing.

## Editing

Do not edit `index.html` by hand. It is generated from `PRIVACY.md` in the
AlarmX repository so the hosted policy and the one shipped with the source
cannot drift apart:

```
python tool/build_privacy_page.py
```

Then copy the result here and push.

## What it says, in short

AlarmX has no account system, no server and no analytics. Alarms, history and
progress live in a database on the phone and are never sent anywhere. The only
data that leaves the device is what Google's advertising SDK collects when
someone chooses to watch an ad.
